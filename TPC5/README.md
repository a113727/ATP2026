## RESUMO
O TPC5 consiste numa aplicação em Python para gerir uma turma de alunos (onde cada aluno é um tuplo com nome, ID e notas, e a turma é uma lista). O programa deve funcionar com um menu interativo contínuo para criar, inserir, listar, consultar por ID, guardar e carregar dados de um ficheiro. O objetivo final é utilizar a aplicação para registar uma turma de 5 alunos.
